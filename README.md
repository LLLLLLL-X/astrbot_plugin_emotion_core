# 情绪核心 · astrbot_plugin_emotion_core

给角色一颗**会变的心**，而不是一堆记忆。

AstrBot 4.x 插件，不依赖任何第三方包。它让角色拥有九个缓慢变化的心理维度、两条快变量（期待 / 责怪压力）、四种状态（平静 / 委屈 / 害怕 / 关闭），以及一层**会自己冒出来、也能被喂饱的念头**（想被夸、想被他找、想找点事做……），并在合适的时候**主动开口**——可以是文字，也可以直接发语音。

> 和"记忆插件"的分工：记忆插件负责**她记得什么**，情绪核心负责**她此刻是什么心情、在惦记什么**。两者 coexist，互不改写。

---

## 1. 它做什么

| 能力 | 说明 |
|---|---|
| 九维驱动 | 依恋 / 好奇 / 反刍 / 责任 / 社交 / 疲惫 / 亲密 / 压力 / 喜悦，0–100，45 分钟慢心跳（最低 15 分钟），会向基线回落 |
| 两条快变量 | `expectation` 期待（她主动开口后你没回）、`blame_pressure` 责怪压力（你凶了她） |
| 四档状态 | 平静 0–25 / 委屈 25–55 / 害怕 55–80 / 关闭 80+ |
| 真假哄辨识 | 她委屈时"行了别闹了"会**加重**，"对不起我错了"才算哄；害怕/关闭需要连续 2–3 轮才回一点 |
| 心结 | 大冤枉没人哄，最多褪到 40 就卡住；小冤枉 6 小时后正常褪干净 |
| 念头 | 八类小念头按驱动冒出来，会挂、会惦记、会被满足；满足后留下"心情"，未满足会持续影响主动说话 |
| 心境注入 | 只在"跨档"时把 ≤120 字的心境（状态 + 心情 + 正在惦记的念头）追加到 system prompt，20 分钟节流，不刷屏、不烧 token |
| 主动说话 | 优先围绕"正在惦记的念头"开口；带冷却 6h、每日 4 条、刚聊过不打扰、夜间免打扰 |
| 主动语音 | 复用 `astrbot_plugin_tts_emotion_router` 的合成能力（**同一套 minimax / 音色配置**），概率随欲望升高；TTS 不在就安静退回文字 |
| 零污染 | 不建第二套记忆、不写记忆库、不 import 其它插件模块、不改任何已有数据 |

它**不做**：不替代记忆、不管人设改写、不做多角色、不训练模型。

## 2. 念头系统（v1.1 新增）

情绪值只决定"大方向"，念头决定"她具体在琢磨什么"。

### 八类念头

每一类由一组驱动的变化决定有没有、要不要冒出来：

| 念头 | 冒出来的条件（Δ = 当前值 − 该类基线） | 你做什么能喂饱它 | 满足后留下的心情 |
|---|---|---|---|
| 想被夸 `praise` | 好奇心涨、心情好 | 夸她（"厉害/真棒/好可爱"） | 开心了一小下 |
| 想被抱 `miss` | 依恋高出基线 | 说"抱抱/想你" | 心里软软的 |
| 想找他说话 `talk` | 社交被冷落、依恋高 | 正常回她话 | 有人说话就不闷了 |
| 想问他今天怎样 `ask_day` | 反刍高、好奇高 | 讲讲你的一天 | 知道你今天怎样，安心了 |
| 想找点事做 `task` | 责任感涨 | 给她一个任务 | 帮上忙了，有点小得意 |
| 想安静一会儿 `quiet` | 疲惫高、压力大 | 别硬找她、给她空间 | 歇够了，好多了 |
| 想撒个娇 `hug` | 亲密高、心情好 | 温柔回应、顺着她 | 被哄到的感觉真好 |
| 在等他回话 `dwell` | 她主动开口了、你还没回 | 回她一句 | 他回我了，心里踏实了 |

### 生命周期

每条念头就三态：

- `pending` —— 她在惦记（注入时会被写成"你心里在惦记：…"）
- `attempted` —— 她已经主动开口了，你还没满足它
- `done` —— 满足（或判负满足），带着一句心情，2 小时后淡出

满足判定按优先级：**事件反推**（她主动开口 → 你先回的？先回满足 `dwell`，给半奖励）→ **文本反推**（你这句是夸、是哄、还是安排任务）→ **事件匹配**（`praise` 喂 `praise` 类、`reply_fast` 兜底"被听见了"半奖励）。

没喂饱会怎样：24 小时后软过期从注入里撤掉、但留到 72 小时；她为此开口过 2 次而你一直没应 → 这条念头"劲头"泄一点，超过 4 次就放弃。惦记的时间越久，主动开口的动机越高。

### 与主动性联动

- 有心念头的会话，主动开口概率额外 +15%（`thought.proactive_push`）
- 真要开口时，先看她有没有 `pending` 念头，有就**围绕这个念头说**，而不是随机抽一句

### 可调

| 键 | 默认 | 说明 |
|---|---|---|
| `thought.enabled` | 开 | 念头系统总开关 |
| `thought.min_weight` | 0.2 | 入池门槛：驱动超过基线多少才凝成念头，调高更"佛系" |
| `thought.ttl_hours` | 24 | 念头最长挂多久（软过期；硬过期是 3 倍） |
| `thought.proactive_push` | 0.15 | 有念头时给主动说话的概率加成 |

## 3. 安装

### 方式 A：目录拷贝（推荐）

1. 把整个 `astrbot_plugin_emotion_core` 文件夹放进：
   `D:\AstrBot\data\plugins\`
2. 重启 AstrBot（或在 WebUI「插件管理」里点重载）
3. 打开插件配置，确认「总开关」为开

### 方式 B：WebUI 上传

把本文件夹压成 zip（**根目录就是 `astrbot_plugin_emotion_core/`**），WebUI → 插件管理 → 安装插件 → 上传。

### 依赖

- AstrBot **≥ 4.16**（用到 `Context.send_message` / `send_message` 直发链路）
- Python 3.10+，仅标准库
- 可选：`astrbot_plugin_tts_emotion_router`（想要主动语音时装）

## 4. 配置要点

配置文件里每一项都有中文说明，这里只说**容易踩的几个**：

| 键 | 默认 | 说明 |
|---|---|---|
| `proactive.target_umo` | 空 | 主动说话发到哪个会话。留空 = 自动记住最近跟她说话的会话。查法：在 QQ 里发 `/情绪 umo`，把结果填进来即可（长期稳定建议填死） |
| `proactive.quiet_hours` | `01:30-07:30` | 这段时间不发，但开机后允许补发 1 条 |
| `voice.enabled` | 开 | 只是"允许尝试"，真正发不发由概率决定；TTS 插件缺失时自动降级为纯文字，不会报错 |

调参建议：
- 想让她**更黏人**：`proactive.daily_limit` 提到 6，`cooldown_hours` 降到 3
- 想让她**更安静**：`cooldown_hours` 提到 12，`daily_limit` 降到 2
- 嫌注入太频繁：`inject.min_gap_minutes` 提到 60

## 5. 命令

在聊天里（默认前缀 `/`）：

```
/情绪              查看当前心境（九维条 + 状态 + 心情 + 念头 + 上次主动说话）
/情绪 status       同上
/情绪 reset        重置为初始状态（只清情绪数据，不动记忆）
/情绪 tick         手动跳一次心跳（调试用）
/情绪 off / on     本次运行内开关
/情绪 umo          查看当前会话 UMO（填配置用）
```

## 6. 与其它插件的关系（重要）

**优先级**：AstrBot 按优先级**降序**执行 `on_llm_request`。本插件固定用 `priority=-10`，即**最后执行**，只做"在 system prompt 末尾追加"，不会覆盖天使之心（`priority=40`）注入的记忆内容，也不会覆盖 TTS（`0`）的提示。

**EMO 标记**：TTS 插件在 `on_llm_response(priority=1)` 里会把 `[EMO:xxx]` 从回复里 **strip 掉**。本插件用 `priority=2` **抢在它前面只读一份**，不删除标记，所以 TTS 的行为完全不受影响。

**不叠加**：不写 memories 表、不建 sqlite 记忆库、不注册任何记忆类 LLM 工具、不调用 angel_memory 的任何方法。

**主动说话不走 event 管线**：直接用 `Context.send_message` 出站（成品消息），因此**不会被其它插件二次加工**（这也是它稳定的原因）；需要语音时单独调 TTS 合成后发一条 `Record`。

**纯标准库**：只有一个自带的 `thought_engine.py`（纯函数、无 AstrBot 依赖），可选地自动生成念头；没有它也会退化成一个固定念头池。

## 7. 数据与隐私

- 全部状态在：`data/plugin_data/astrbot_plugin_emotion_core/state.json`
- 里面只有：九维数值、期待/责怪、状态档、念头列表（每条约 100 字）、最近 **30 条**消息的**前 200 字摘要**（用于主动说话时给 LLM 一点上下文），**不存聊天全文、不存图片、不存记忆**
- 卸载 = 删插件目录 + 删上面那个文件夹，**不会留下任何东西**，也不影响记忆插件的数据

## 8. 已知限制

1. **主动语音用默认情绪**：TTS 的"按情绪换语气"依赖它在回复链上读 EMO 标记；主动说话没有回复链，所以用的是 TTS 配置里的默认 `emotion`。想改就改 TTS 插件那边的默认值。
2. **语音不会换人**：`voice_map` 里 19 种情绪若都指向同一个音色（常见配置），那就只有语气变化、没有音色变化。要换音色需要在 TTS 插件里配多个 voice。
3. **LLM 不可用时**会退到内置的兜底台词（每型 3 句），保证她不会一声不吭。
4. **单会话假设**：默认只服务"最近跟她说话的那个会话"（`target_umo`）。多人群聊场景建议显式填 `target_umo`。
5. **念头满足靠"事件反推"**：她心里想要什么、你这句算不算喂饱，是根据你这句里有没有关键词/事件猜的，偶尔会猜偏；不确定时她会按"半奖励"处理，不会完全不讲理。

---

## 9. 卸载

1. WebUI 插件管理里禁用并删除，或直接删 `data/plugins/astrbot_plugin_emotion_core`
2. 删 `data/plugin_data/astrbot_plugin_emotion_core/`
3. 重启 AstrBot

不会留下后台任务（`terminate()` 里会 cancel 心跳协程）。
